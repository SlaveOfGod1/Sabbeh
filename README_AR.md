## ✨ المميزات

### 🔢 العداد الرقمي
- شاشة رقمية كبيرة وواضحة
- تتبع الجولات تلقائياً عند الوصول للهدف
- إعادة ضبط العداد بضغطة واحدة

### 📿 جلسات الذكر
- **أذكار مخصصة**: أضف أذكارك الخاصة مع عناوين وأهداف مخصصة
- **التعديل والحذف**: اضغط مطولاً على أي ذكر لتعديله أو حذفه
- حفظ التقدم لكل جلسة ذكر

### 🎨 الثيمات والتخصيص
- **٤ ثيمات جاهزة**: فيروزي، بنفسجي، أزرق، وردي
- **منتقي الألوان**: اختر أي لون يعجبك
- **الوضع الليلي**: ثيم داكن للاستخدام المريح ليلاً

### 🌍 دعم متعدد اللغات
مترجم بالكامل لـ ٧ لغات:
- English (الإنجليزية)
- العربية
- Türkçe (التركية)
- 中文 (الصينية)
- Bahasa Melayu (المالزية)
- اردو (الأردية)
- 日本語 (اليابانية)

### 💾 إدارة البيانات
- **تصدير الملف الشخصي**: احفظ بياناتك كملف JSON
- **استيراد الملف الشخصي**: استعد بياناتك من نسخة احتياطية
- **إعادة ضبط البيانات**: امسح جميع البيانات وابدأ من جديد

### 🛡️ الخصوصية أولاً
- ✅ بدون إعلانات
- ✅ بدون متتبعات
- ✅ بدون جمع بيانات
- ✅ يعمل بدون إنترنت

## 🚀 البدء

### المتطلبات
- [Node.js](https://nodejs.org/) (الإصدار 18 أو أعلى)
- [npm](https://www.npmjs.com/) أو [yarn](https://yarnpkg.com/)
- [Expo CLI](https://docs.expo.dev/get-started/installation/)

### التثبيت

1. **استنساخ المستودع**
   ```bash
   git clone https://github.com/SlaveOfGod1/Sabbeh.git
   cd Sabbeh
   ```

2. **تثبيت التبعيات**
   ```bash
   npm install
   ```

3. **تشغيل خادم التطوير**
   ```bash
   npx expo start
   ```

4. **التشغيل على جهازك**
   - امسح رمز QR بتطبيق [Expo Go](https://expo.dev/client)
   - أو اضغط `a` للمحاكي الأندرويد / `i` لمحاكي iOS
